# Pong 2.0

A modern recreation of the classic Pong game built with Python and Pygame.

## Controls
- `Up Arrow` / `Down Arrow`: Move player paddle
- `ESC` / Close window: Quit and save score

## Run Locally
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Start the game:
   ```bash
   python main.py
   ```
